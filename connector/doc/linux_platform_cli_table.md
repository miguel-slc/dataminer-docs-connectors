# Linux Platform CLI Table

This table is available in the page *General* > *CLI Table*.

The CLI table is a special feature available in the Linux Platform connector. It allows users to execute custom commands on the target Linux machines and retrieve their output for monitoring and analysis.

The table contains the following columns:

- Display Key: This column contains a unique identifier for each command entry. It is used to reference the command in other parts of the system.
- Command: This column contains the actual command that will be executed on the target Linux machine. It can be any valid Linux command or script.
- Description: This optional column provides a brief description of the command's purpose or functionality. It helps users understand what the command does and its relevance to the monitoring process.
- Response: This column captures the output or response generated by the executed command. It can include text, numerical values, or any other relevant information returned by the command. In case the response contains multiple lines, only the first line will be displayed in the table, while the complete response can be accessed by copying the command output from the table.

> [!NOTE]
> It could be the case that the response contains empty lines at the beginning. In this case, the response will look empty in the table, but the complete response can be accessed by copying the command output from the table.

- Action (Execute): This button allows the command to be executed on demand. When clicked, the command will be sent to the target Linux machine for execution, and the response will be updated in the Response column.
- Polling Frequency: This column specifies the interval at which the command will be automatically executed and the response updated. It allows users to set a desired polling frequency for continuous monitoring of the command's output. By default, the polling frequency is set to 30 minutes.
- Remote Element ID: In case the response of the command needs to be sent to another element for further processing, this column allows users to specify the Element ID of the target element. The expected format is DataMiner ID/Element ID.
- Last Polled Time: This column displays the timestamp of the last successful execution of the command.
- Status: This column allows users to enable or disable the command entry. When enabled, the command will be executed according to the specified polling frequency. When disabled, the command will not be executed, and the corresponding response column will not be updated.

## Adding a command entry

1. Right-click on the table to access the context menu.

2. Select "Add row...".

   A dialog box will be displayed.

3. Enter the necessary details for the new command entry:
   - Command
   - Polling frequency
   - Remote element ID (if applicable; default value is -1)

4. Click "OK" to add the new command entry to the CLI table.

## Removing a command entry

1. Right-click on the desired row to be removed to access the context menu.

2. Select "Remove row".

   A confirmation dialog will be displayed.

3. Click "OK" to confirm the removal.

   The command entry will be removed from the CLI table.

> [!IMPORTANT]
> - When adding command entries, make sure that the command is not interactive and does not require user input. Interactive commands will cause the connnector to go into timeout and will not return any response. If this happens, disable the command entry (or remove it) and restart the element.
> - Commands that require elevated privileges (e.g., using `sudo`) may not work as expected, depending on the SSH configuration and user permissions. Ensure that the user executing the commands has the necessary permissions to run them without requiring a password prompt.
